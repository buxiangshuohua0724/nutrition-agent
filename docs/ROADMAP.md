## 已知技术债务与后续项

- [ ] **RAG 语义检索**：第一版仅实现关键词检索（PRD FR-010 要求"后续支持语义向量检索"）
- [ ] **对象存储**：第一版图片落本地磁盘，生产需替换为对象存储（PRD FR-006 流程第 3 步）
- [ ] **LLM 适配器**：需配置真实模型服务的密钥；未配置时降级为确定性桩实现
- [ ] **视觉模型**：需接入多模态模型；未接入时识别接口返回明确的"服务不可用"
- [ ] **营养数据规模**：种子数据仅用于流程验证，需按权威来源扩充至 50~100 种食品
